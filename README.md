# Folder Privacy Auditor — Windows

フォルダーを指定して、**ファイル数・容量・個人情報らしい文字列・隠しファイル・重複候補**を読み取り専用で確認します。

基本操作: **フォルダーを選ぶ → 検査する → 必要ならCSV/JSONレポートを出力**。自動削除、ファイル移動、修復は行いません。

**重要:** 検査できた内容と未検査内容を別々に表示します。PDF・画像・Excel・バイナリ等は形式ごとの完全な内容解析には対応していません。未検査や検出なしを「安全」とはみなしません。

シンボリックリンク・ジャンクション等は追跡せず、未検査として記録します。検査できないフォルダー、読み取れないファイル、大きすぎるファイル、ファイル数の制限も確認対象に含めます。出力レポートは、元フォルダーの外に新規作成し、既存のレポートは上書きしません。

`main` の Storage Cause AnalyzerとWindows向け検証資産は変更せずに保護しています。

テスト・制限・販売条件は [WINDOWS.md](WINDOWS.md) を参照してください。**Microsoft Store販売: HOLD（未承認）**。
